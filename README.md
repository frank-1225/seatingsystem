🎯 智能会场排座系统 (Intelligent Venue Seating System)一款专为政企办公、大型会议、高峰论坛设计的“开箱即用”智能会场排座与签到管理系统。告别人工排座的繁琐与易错，提供从“名单导入 ➔ 可视化布局 ➔ 智能排座 ➔ Excel与短信导出”的一站式闭环体验。
✨ 核心特性
1. 极度灵活的会场可视化编辑器双引擎画布：主席台与主会场独立分离，均支持高度自定义。乐高式交互：支持右键单击图表外圈，一键插入/删除行列、设置走廊/过道/立柱废座。所有坐标系（如1排、2排、V1座）支持自定义文本且智能顺延。
   区域调色盘：使用笔刷自由框选“VIP区”、“媒体区”等专属色彩区域，自动适配高对比度黑白文字。模板复用：精心排布的会场布局可一键保存为模板，供未来其他会议无缝调用。
2. 强大的“中央”排座算法引擎多流派数学排布：支持从左到右、从右到左、蛇形折返填入。物理中轴线劈开：独创绝对物理中心锚定算法！自动侦测会场或色彩区域的真实中心线，实现“主位居中，先左后右/先右后左”的完美对称排布（完美兼容单双数座位）。
3. 自定义连线排座：面对复杂畸形区域，可开启“自定义区域排座次序”模式，鼠标点击 1,2,3... 绘制专属路线，引擎将严格按此连线填入人员。
4. “强联动”的人员管理与补位机制拖拽即洗牌：在左侧人员名单中上下拖拽更改人员顺位，右侧画布中已落座的对应人员将自动平滑换位（绝不跨区填坑）。智能缺席补位：右键点单击图上某入座人员选择“缺席”，系统不仅会将其移除，还会令其后方所有人自动沿着算法路线前移一格补位，完美化解临时不来的尴尬。
5. 多租户数据隔离：所有数据按“会议”独立存档，全局毫秒级自动保存，防丢失。
6. 生产力级别的导出体系三合一 Excel 导出：一键导出包含“所见即所得的彩色方格布局图”、“大区明细签到表”、“全变量短信清单”的 Excel 文档。
   富文本方格设定：自由组合 {姓名}、{单位} 与 换行符，定义 Excel 最终生成的方格内部格式。全量字段短信引擎：导入名单时自带的所有未知表头（如“接机航班”、“餐饮忌口”），系统均会自动抓取生成为 {变量标签}，可一键插入签到短信模板中供群发使用。
7. 技术栈后端：Python + Flask + SQLite (轻量级本地存储，无需配置外置数据库)前端：Vue 3 (Composition API / CDN) + TailwindCSS (纯原生 HTML 嵌入，无 Node.js 编译负担)数据处理：Pandas (名单处理) + OpenPyXL (原生 Excel 级色彩网格渲染)

🚀 快速部署 (Docker 推荐)本项目已完全容器化，只需包含三个核心文件（app.py, requirements.txt, Dockerfile）即可在任何服务器上一键启动。
方式一：Docker CLI 一键运行
# 1. 构建镜像
docker build -t seating-system .
# 2. 启动容器 (映射本地 5000 端口，并挂载 SQLite 数据库确保持久化)
docker run -d \
  -p 5000:5000 \
  --name my-seating-system \
  -v $(pwd)/seating.db:/app/seating.db \
  seating-system

方式二：Docker Compose新建 docker-compose.yml 文件：

version: '3.8'
services:
  seating-web:
    build: .
    ports:
      - "5000:5000"
    volumes:
      - ./seating.db:/app/seating.db
    restart: always
运行：docker-compose up -d

部署完成后，打开浏览器访问 http://localhost:5000 即可开始使用！
📖 标准使用流四步曲会场设置：
新建会议 -> 搭建主席台与主会场 -> 画出走廊及废座 -> 使用笔刷框选出“特定功能区”。导入名单：导入 Excel/CSV 人员名单 -> 在系统中利用拖拽或修改序号进行最终排序。分配落座：选定主席台填入核心领导。选定特定功能区填入对口人员。选定主会场全局，一键填补剩余所有人员。微调与导出：图上右键对零星位置进行“强绑”或“补位” -> 配置好短信模板 -> 下载最终的 Excel 会务总表。
