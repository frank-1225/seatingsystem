# 智能会场排座系统

面向政企会议、大型活动和宴请场景的可视化排座工具，提供从名单导入、会场布局、自动排座到 Excel 与短信清单导出的完整流程。

## 支持的会议布局

- 课桌式：独立配置主席台与主会场，支持行列编辑、功能区着色、走廊和禁用座位。主席台默认主位居中偏左，按“先右后左”向两边排号和落座；整列设为走廊后，后续座号自动连续重排。
- 长会议桌式：围绕长会议桌配置上、下、左、右四边座位；每边座位数可从 0 开始自由设置，各边座位相对桌面中轴居中，并可单独设置座间距和左右桌外主位。座位数不限制桌面最小尺寸，桌面横边和竖边始终至少保持 3 个座位所占的宽度。主方与宾方可自由交换上下两侧；任一方的上／下侧座位不足时，都会同时向左、右两侧延伸，并从靠近自己的一端向对方方向排列。
- 圆桌式：支持多张圆桌、每桌多圈座位以及座位数和半径设置；主方从主位逆时针、宾方从右首顺时针，分别按照各自名单次序落座。可开启“主宾双主位”，让主人 1 号与宾客 1 号在 12 点方向左右并列，其他座次与名单顺序不变。
- U 型桌式：领导席可放在上边或下边，对侧显示 PPT／演讲台，中间保持开放无桌面；左右参会席可分别设置列数和每列座位数，第 1 列为靠近开放区的内列。参会人员从靠近领导的一端开始，同一距离先内列后外列排列；领导在下方时，领导席座次会相对上方布局左右镜像。

切换布局时，人员名单会保留，当前座位安排会在确认后清空。长桌或圆桌增减座位时，系统以主方、宾方各自的名单次序为固定锚点，在新座位结构中按原路线稳定重排；U 型桌则以领导席居中顺序和两侧距领导远近为固定锚点。减少座位时系统先删空座，总容量不足时才会移除人员，并明确提示姓名。各桌型的配置、座位状态及自定义显示字段会随会议自动保存，也可以保存为布局模板。

## 核心能力

- Excel/CSV 名单导入，自动识别姓名、单位、类别、电话和额外字段。
- 长桌和圆桌名单可区分“主方（上级）”“宾方（下级）”，支持单人或批量分类、分组筛选及两套独立序号；导入文件可使用“主宾”“主宾身份”“所属方”“主客”或“身份”列。
- 可视化座位编辑，支持走廊、禁用座位、右键强制安排、缺席补位和撤销。
- 课桌式支持区域着色、自定义连线顺序、居中排座、左右排座及蛇形排座。
- 长会议桌式支持居中向外、从左到右、从右到左和蛇形排座。
- 圆桌式支持中式宴请、顺时针和逆时针排座，12 点钟方向为主位。
- U 型桌式支持领导席上下切换、左右多列分别设置，以及从领导近端开始、同距离由内向外的交替自动排座。
- 按会议隔离数据并自动保存，可复用布局模板。
- 一键导出会场布局、签到表和短信群发清单；长会议桌、圆桌和 U 型桌导出使用可读的桌号、方位、圈名和座号。

## 快速启动

### 本地运行

```bash
pip install -r requirements.txt
python app.py
```

打开 <http://localhost:5000>。

### Docker

```bash
docker build -t seating-system .
docker run -d \
  -p 5000:5000 \
  --name seating-system \
  -v $(pwd)/seating.db:/app/seating.db \
  seating-system
```

## 使用流程

1. 新建会议，在“会场设置”中选择课桌式、长会议桌式、圆桌式或 U 型桌式。
2. 配置座位数量和桌型，按需设置走廊、禁用座位及自定义座号；长桌可指定主方、宾方的上下位置，系统会在本侧不足时自动同时使用左右延伸席。
3. 导入参会名单；使用长桌或圆桌时，先区分主方/宾方，再分别调整两方内部顺序。
4. 在“区域排座”中选择“主宾自动对坐”或“主宾分序自动排座”，批量安排人员。
5. 右键微调座位，在“导出发布”中下载 Excel 会务总表。
